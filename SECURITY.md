# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Pergel, please report it responsibly:

- **Do NOT** open a public GitHub issue.
- Use [GitHub's private vulnerability reporting](https://github.com/sametatakan0000-netizen/pergel/security/advisories/new).
- Or email: security@pergel.dev

We will acknowledge receipt within 48 hours and provide a fix timeline within 7 days.

## Scope

Pergel's security model is **defence, not evasion**:

- SSRF/egress protection for all network requests
- No telemetry, no data collection, no phone-home
- BYOK (Bring Your Own Key) — your AI keys stay local
- No stealth/anti-detection for bypassing paywalls or bot walls

## Supported Versions

Only the latest version on `main` receives security updates.
